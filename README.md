# مزرعتي — مصادر المشروع

نسخة قابلة للاستنساخ والعمل عليها من حاسبة ثانية. أحدث مصدر الويب مأخوذ من الإصدار المنشور `d2d6b37` بتاريخ 8 أكتوبر 2026 بتوقيت بغداد.

## المحتويات وحالتها

- `website/app/`: التطبيق المستقل الحالي وخادمه، بواجهتي `/customer` و`/owner`. يتضمن الفترتين الصباحية والمسائية، حسابات الهاتف عبر Twilio Verify، تقويم التوفر، الإلغاء داخل التطبيق، وقسم الأكثر حجزاً حسب الحجوزات المؤكدة. لا يعتمد على Wix.
- `android/customer/` و`android/owner/`: غلافا Android المتصلان بالموقع الحالي. ملفات البناء تولّد مفتاح تجربة جديد محلياً؛ لم يُرفع أي مفتاح توقيع.
- `ios-legacy/`: مشروع Xcode وملفات SwiftUI أصلية موجودة فعلاً. **هذه نسخة أقدم تعتمد على واجهات Wix و`/api/v1`؛ لم تُحدّث لتوافق الخادم المستقل `/api/v2`، ولم تُجمّع أو تُختبر في Xcode. لا تعتبرها تطبيق iOS جاهزاً للنشر.** اقرأ README داخلها قبل العمل.
- `SETUP.md`: متطلبات الإعداد والعمل من جهاز آخر.

الموقع الحالي: https://mazraaty-iraq.higgsfield.app

هذا المستودع نسخة مصادر؛ دفع تغييرات إلى GitHub لا ينشرها تلقائياً إلى Higgsfield. أسرار الخادم وبيانات الزبائن وصور المزارع المرفوعة محفوظة في خدمة الاستضافة وليست جزءاً من هذا المستودع. يلزم دخول الحساب الأصلي لإدارة هذه الموارد.

## تجهيز Cloudflare المستقل

إعدادات المرحلة الأولى للنقل إلى Cloudflare موجودة في `website/app/CLOUDFLARE.md`.
الهدف Worker جديد `mazraati`، وقاعدة فارغة `mazraaty-db` وتخزين فارغ
`mazraaty-photos`، دون نقل البيانات التجريبية القديمة. الدفع إلى GitHub يشغّل
الفحوصات فقط؛ نشر Cloudflare يدوي ويتطلب إعداد الحساب والموارد أولاً.
الموقع الحالي وبيانات Higgsfield لم يُعدّلا بهذه المرحلة.

## على حاسبة ثانية

1. سجّل دخول GitHub Desktop بنفس حسابك، ثم اختر File → Clone repository واختر هذا المستودع.
2. افتح مجلد المستودع في Codex كـ Project. ابدأ بقراءة `SETUP.md` و`AGENTS.md`.
3. لتعديل الخادم الحالي استخدم `website/app/`. ولإكمال iOS استخدم Mac وXcode، وابدأ بتحديث الربط إلى واجهات `/api/v2` كما هو موضح في `SETUP.md`.

لم تُرفع كلمات مرور أو مفاتيح Twilio أو شهادات Apple أو قاعدة بيانات الإنتاج.
