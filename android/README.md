# مزرعتي — تطبيقان متصلان

نسخة تجريبية لأندرويد 7 أو أحدث، تحتاج الإنترنت. تطبيق الزبون للعرض وطلبات الحجز؛ تطبيق الإدارة لإضافة وتعديل ونشر وإخفاء المزارع وإدارة الحجوزات. البيانات مشتركة بخادم مستقل عن Wix.

ثبّت Mazraaty-Customer-test.apk للزبائن وMazraaty-Owner-test.apk للإدارة. كلمة الإدارة محفوظة بملف منفصل خاص بالمالك ولا تُضمّن بالكود أو ملفات APK. عند إضافة مزرعة اختر «نشر» حتى تظهر للزبائن. طلب الحجز يحتاج موافقة الإدارة؛ تأكيد الحجز لا يعني دفع المال. دفع QI مؤجل لحين حساب تاجر.

هذه تطبيقات WebView تحمل واجهة الخادم الآمنة. تحديث واجهة الخادم يظهر بالتطبيقين. لتعديل غلاف أندرويد استعمل المصادر هنا وأعد البناء. تتطلب ملفات build.sh نظام Bash وJDK وأدوات Android SDK build-tools 35.0.0 وplatform android-35، واضبط ANDROID_SDK_ROOT. شغّل customer/build.sh ثم owner/build.sh. مفتاح التوقيع المرفق للتجربة فقط؛ استخدم مفتاح إنتاج منفصل قبل نشر المتجر.

تطبيق الإدارة الآن يفتح `https://mazraati-preview.laithlaith500.workers.dev/owner` على Cloudflare.
تطبيق الزبون الآن يفتح `https://mazraati-preview.laithlaith500.workers.dev/customer`. على Windows يمكن بناء الإدارة عبر
`./owner/build.ps1` بعد ضبط `JAVA_HOME` و`ANDROID_SDK_ROOT`.
مفتاح التجربة يولّد محلياً ويُستثنى من Git؛ تثبيت تحديث فوق نسخة قديمة يحتاج
نفس مفتاح توقيع تلك النسخة. كلمة الإدارة وأسرار Twilio لا تُضمّن في APK.
يبني GitHub Actions تطبيق الإدارة عند تعديل مصادره على فرع النقل، ويرفع APK
ضمن ملف `Mazraaty-Owner-Cloudflare-test`؛ ويبني تطبيق الزبون عند تعديل مصادره ضمن `Mazraaty-Customer-Cloudflare-test`. مفتاح توقيع هذا البناء تجريبي ومؤقت؛
لا يصلح لضمان تحديث نسخة مثبتة سابقاً، ولا يُرفع ضمن المخرجات.

اجتازت نسخة الخادم اختبارات صلاحيات الإدارة والحجز ومنع تأكيد الحجز المزدوج، وفحص البناء والواجهة. تم التحقق من توقيع ملفي APK؛ لم تُجرّب النسخة على هاتف أندرويد فعلي بعد.

نسختا Android الحاليتان للفحص فقط وترتبطان بقاعدة وصور التجربة المنفصلة.
الدخول للزبون بحساب ورمز تجريبيين، دون SMS أو توثيق هاتف حقيقي.
عند الإطلاق نعيد ربط الغلافين بنطاق الإطلاق بعد تفعيل Twilio ونستخدم توقيعاً ثابتاً خاصاً.
